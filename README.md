# Cuadernos de MiAtlas.cl

Cuadernos de Google Colab del curso **«Google Colab»** de la Academia de [MiAtlas.cl](https://miatlas.cl).

Cada cuaderno se abre con el botón **«Abrir en Colab»** del tema correspondiente y corre en **tu propia cuenta de
Google**, con la GPU gratuita de Colab cuando esté disponible. MiAtlas.cl no recibe tus datos ni tus claves.

> Este repositorio se publica desde MiAtlas.cl: no se edita a mano. Las correcciones se proponen en el curso.
